02–03 / FOR PEOPLE & PLATFORMS

实时搜索与实时推荐

实时搜索

询问真实世界的此刻

自然语言查询现实中的人流、路况、停车和现场状态，给出有时效性的结果及证据。

实时推荐

把状态变化转化为选择

综合当前状态和可用的趋势判断，为出行、本地生活等场景提供时机与方案建议。

Interface sketch · search
钟山景区附近哪里方便停车？
停车判断根据已接入停车场的最新状态比较空位、距离和入口位置。
状态时间 / 数据来源 / 可用范围需在实际系统中显示
Interface sketch · recommendation
现在适合去山顶看云海吗？
出行建议依据天气、设施开放状态和预计到达时间，给出适合出发的条件与备选方案。

04 / SCENE AGENT

场景智能体

面向具有真实运营责任的机构，把状态理解、辅助判断与业务动作连成可核验的流程。

城市治理事件发现与处置

发现复杂事件、辅助研判、派单流转、现场回传与结果核验。

文旅景区景区运营与游客服务

统一客流与设施状态，提供调度建议、动态游览与服务引导。

交通枢纽客流与应急场景包

围绕客流变化、设施状态和异常事件开展辅助研判。具体能力按项目核定。

工业与园区安全及运营场景包

将现场感知、事件记录与管理流程联动。适用范围需结合行业要求验证。

统一的四类角色入口

A运营中心

全域态势总览和资源监测。

B管理智能体

自然语言研判、辅助调度。

C一线应用

事件回传、处置复核。

D / 游客与服务端

动态出行建议、路径选择以及必要的消费与服务引导。与管理端共享同一状态底座。

城市治理为已运行的重要业务方向；其他场景包的功能和商业成熟度需依具体项目说明，不宜合并宣称全部已规模部署。

Physical AI 外部状态与数据服务

长期方向

面向机器人、无人机与自动驾驶系统，探索全球和局部环境状态、真实场景数据及训练反馈等外部能力。

真实场景数据

基于合规授权的数据采集、整理与应用，支持研发和验证需求。

API 具体字段、调用限制、服务等级和计费方式需要接口文档核对；Physical AI 服务明确作为长期方向介绍。
