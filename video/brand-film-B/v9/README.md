172.2 秒，1920×1080，25fps。在 v8 代码基础上按 2026-11-03 定稿解说词重做。

## 运行

```bash
cd ../src
python3 snap9.py 35,99.4 s9x          # 截取指定秒数的静帧到 s9x/（脚本自带本地服务）
DSF=1 Q=93 python3 rend9.py 0 4305 /tmp/hd    # 逐帧渲染（可分两段并行）
ffmpeg -framerate 25 -i /tmp/hd/%05d.jpg -i mixV9.flac -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -b:a 256k -shortest out.mp4
```

`DSF=0.5` 出 960×540 低清预览。

## 时间与声音的处理

- 2026-11-04：「每一条信息，都带着四个要素……」一句移到「在 SeeMind 里，它们说同一种语言」之后，「这样的分工……」因此紧接「感官各自分工」；画面相应把 S15 四要素移到 S11 中间（S11 拆成前后两段）。
- 原录音 158.6 秒，句间停顿很短。按意思远近在 32 处句间插入静音（0.25–0.8 秒，共 12.95 秒），并剪掉"方｜见真相"之间 0.08 秒的停顿。
- 画面不靠放慢来填气口：每个镜头按正常速度播放并延长到下一句开口前；镜头内若含多句，只在句与句之间做轻微匀速拉伸。
- 转场只发生在上一句说完、下一句开口之前的空隙里。
- 配乐：Wonders of the Earth（Pixabay），在 23.8–53.05 秒处循环一次补足长度；人声整体 +16 dB，配乐压在人声下并随人声自动避让。商用许可正式发布前需确认。
